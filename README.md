# 틈 플래너

> 할 일과 약속을 아무렇게나 적으면 AI가 항목별로 정리하고, 직접 설계한 스케줄링 알고리즘이 빈 시간에 자동으로 배치해 주는 일정 웹 비서.

OSS 기반 SW 프로그래밍 학기 프로젝트 (개인, 16주)

---

## 1. 프로젝트 개요

**틈 플래너**

할 일과 약속을 아무렇게나 적으면 AI가 항목별로 정리하고, 직접 설계한 스케줄링 알고리즘이 빈 시간에 자동으로 배치해 주는 일정 웹 비서.

## 2. 문제 정의

일정 관리 앱은 많지만, 항상 쓰려고 하면 제목, 날짜, 시간을 칸에 맞춰 직접 입력해야하는 수고로움이 있다. 바쁠수록 이 과정을 건너뛰게 되고, 할 일은 메모장과 메신저에 흩어진 채 마감 직전에야 다시 떠올라 시간에 쫓기게 된다. 막상 정리해도 **언제 할지를 정하는 일은 여전히 사람 몫이다.**

- **문제:** 입력이 번거로워 일정 관리가 지속되지 않고, 할 일을 시간표에 배치하는 판단까지 사용자가 떠안게 된다.
- **대상:** 과제, 시험, 아르바이트 등의 바쁜 일정에 약속이 뒤섞인 대학생, 일정이 자주 바뀌는 1인 작업자(프리랜서) 등
- **기존 서비스들의 한계:** Motion, Reclaim같은 AI 일정 서비스는 영어 중심의 유료 서비스이고, 왜 그 시간에 배치했는지에 대한 변별력과 설명이 부족하다.
- **차별점:** 한국어로 대충 쏟아낸 메모를 그대로 받아 정리하고, 배치 결과마다 <ins>마감이 가장 급해서 오늘 저녁에 넣었어요</ins>처럼 **타당한 이유**를 함께 제공한다.

## 3. 핵심 기능

| 기능 | 설명 |
| :---: | --- |
| **막 적기** | "내일 3시에 치과, 주말에 장보기"처럼 자유롭게 입력하면, AI가 항목마다 제목, 종류, 마감, 예상 소요시간, 우선순위를 뽑아 정해진 JSON 형식으로 돌려준다. 사용자는 저장 전에 결과를 미리 확인하고 직접 고칠 수도 있다. |
| **자동 스케줄링** | **고정 일정(수업, 약속)을 피해** 빈 시간대에 마감 임박도와 우선 순위가 높은 할 일부터 채워 넣는 알고리즘을 직접 구현한다. 긴 작업은 여러 블록으로 쪼개고 일정이 바뀌면 다시 배치한다. |
| **캘린더와 배치 이유** | 주간, 월간 캘린더에 결과를 보여주고, 블록마다 왜 그 시간에 배치했는지 한 줄 설명을 붙인다. 블록을 드래그해 옮기면 나머지 일정도 함께 조정된다. |
| (기타) **역할 분담 원칙** | AI는 문장을 이해하고 정리하는 일만 맡고, 실제 배치는 알고리즘이 맡는다. 일정이 겹치거나 매번 결과가 달라지는 문제를 막고, 핵심 로직을 테스트로 검증 |

## 4. 기술 스택

프론트엔드와 백엔드를 TypeScript 하나로 통일한 Next.js 풀스택 구조
사용하는 라이브러리는 모두 <ins>오픈 소스</ins>

| 영역 | 선택 | 고른 이유 |
| :---: | --- | --- |
| **프레임워크** | Next.js + TypeScript | 기존의 JS 경험을 살려 익숙한 것으로 선택 |
| **DB** | PostgreSQL | 오픈소스 기반, 로그인 기능 내장, 행 단위의 보안으로 사용자별 데이터의 분리 |
| **AI** | Gemini API 무료 티어(Flash) | 별도 비용 발생X |
| **캘린더 UI** | FullCalendar(MIT) | 주간 월간 보기, 드래그 이동을 직접 구현할 수고를 덜 수 있음 |
| **CI 테스트** | Vitest + GitHub Actions | 스케줄링 알고리즘을 단위 테스트로 검증, 푸시마다 자동 실행 |
